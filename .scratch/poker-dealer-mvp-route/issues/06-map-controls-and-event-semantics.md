# Map Rokid controls and input-event semantics

Type: prototype
Status: open
Blocked by: 02, 05

## Question

For every physical device selected by **Choose the MVP physical input devices**, which down/up, click, hold, repeat, swipe, touch, vendor-gesture, and Android key events actually reach Poker or Dealer, and which normalized command mapping safely supports reading, Morse timing, and push-to-talk?

The answer is a measured event map and capability decision, including explicit fallbacks for controls that lack key-up or reliable duration.
