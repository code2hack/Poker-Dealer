# u4090 M1 evidence — 2026-07-27

## Scope

- Host: u4090, Ubuntu/Linux x86-64 with RTX 4090.
- Route: trusted LAN through the route-neutral TCP/duplex-stream dialer.
- SSH: public-key authentication with strict ED25519 host-key pinning under stable host ID `u4090`.
- Codex distribution: official upstream standalone `0.145.0`.
- Daemon: managed PID backend, machine-readable status `running`, app-server `0.145.0`.

Concrete endpoints, keys, host-key material, thread content, and client identifiers are omitted because this repository is public.

## Live check

The opt-in `U4090LiveM1Test` ran on u4090 against an idle existing thread. The final Gradle 9.5.1 test case completed in 4.603 seconds with no skipped steps or failures.

The check established a real TCP connection to u4090's LAN SSH listener, authenticated SSH through the route-neutral stream, queried the running daemon, launched `codex app-server proxy`, completed the WebSocket and `initialize`/`initialized` handshakes, listed threads, resumed and read history, projected existing items into Dealer cards, started one turn, emitted streaming card revisions through completion, opened a fresh connection, reinitialized, reread the thread, and found exactly one user message with the generated client ID.

The reconnect path did not replay `turn/start`.

The production Dealer activity binds to a foreground connection service that owns the same M1 stack across Activity recreation. The service applies the card callback through a revision-aware store, and Dealer renders existing and streaming cards. The Android build and lint gates cover this wiring.

The final Gradle 9.5.1 gate ran `test`, `lint`, and `:apps:dealer:assembleDebug` with the build cache disabled. All 91 tasks executed successfully.

## Limits

- The proof process originated on u4090 and reached its sshd through the host's LAN address. Fold6-to-u4090 behavior remains untested.
- The Dealer activity was compiled and linted but was not exercised on Fold6 hardware in this proof.
- Embedded `tsnet`, external-Tailscale fallback, DERP, VPN coexistence, Android lifecycle, and battery behavior remain M1T work.
- This records one upstream Codex version and does not claim multi-version compatibility.
